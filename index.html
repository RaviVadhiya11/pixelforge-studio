Frequently asked questions

Are all tools free?

The current tools are free to use. Future hosting, API services or optional premium features may have separate costs.

Are my files uploaded?

Most image tasks run locally in your browser. Background removal and PDF tools load libraries/model files from public CDNs, but the selected files are processed in the browser.

Does 4× upscaling create AI detail?

No. The upscaler enlarges pixels with browser interpolation. It is not AI super-resolution and cannot reconstruct missing details.

Why might a format fail?

Some formats such as HEIC, TIFF and AVIF are not supported by every browser. Use JPG, PNG or WebP for the broadest compatibility.
