Privacy policy

Last updated: 25 November 2026

Local images

The current free image workspace processes selected images with browser canvas and local code. The SEO assistant drafts text from user-entered subjects and image dimensions, without a connected AI recognition API. Selected images are not intentionally uploaded to a PixelFire processing server. Avoid processing confidential images on shared devices.

Optional accounts and preferences

Firebase Authentication handles email, authentication credentials, optional display name and password reset. PixelFire does not operate its own password database. Theme and recent tool identifiers may be stored locally. Clear site data through your browser settings. See Firebase privacy information.

Hosting and third parties

The website is hosted by GitHub Pages. Third-party fonts, scripts and authentication services can receive IP addresses, browser details and other technical request data. Other website pages may use Google Analytics, which can collect device and usage data and cookies. See Google Privacy Policy.

Advertising and cookies

The homepage includes an AdSense ownership verification meta tag and the site publishes an ads.txt record. These are not ad placements. Ads are not enabled by the current studio code. If enabled later, Google and its advertising partners may place or read cookies, use web beacons, IP addresses and similar identifiers for ad serving, personalization where permitted, measurement and fraud prevention. Learn how Google uses information from sites using its services and manage ad personalization through My Ad Center. Required consent mechanisms must be implemented before relevant advertising is enabled.

Retention, children and security

Downloaded files are stored where your browser saves them; image data may remain in page memory until the page closes or is replaced. Authentication retention depends on Firebase settings. Use a trusted device and updated browser. General-purpose tools should not be used to process children’s or other people’s personal information without appropriate permission or legal basis.
