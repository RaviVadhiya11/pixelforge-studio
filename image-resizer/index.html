How to use this free online tool

  1. Open the tool using the button above.
  2. Select a file from your phone or computer.
  3. Choose the available settings and run the tool.
  4. Review the output and download it if it meets your needs.

Frequently asked questions

Can I set exact pixels?

Yes, enter the width and height in pixels.

Will the image be stretched?

Choose Fit, Crop or Stretch to control how it is resized.

Can I choose output format?

Supported output choices include original format, JPG, PNG and WebP.

PixelForge Studio tools run in your browser where possible. File-format support, performance and output quality depend on your browser and device. Keep a copy of important original files.
