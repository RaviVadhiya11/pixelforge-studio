How to use this tool

Choose a PDF and save each page as its own PDF file. This tool runs in your browser using a PDF processing library. Large documents may take longer on mobile.

  1. Open the tool using the button above.
  2. Select your PDF file from your device.
  3. Choose the required options and run the tool.
  4. Download the processed PDF when it is ready.

Privacy note: supported processing happens in your browser. The PDF library is loaded from a public CDN. Keep a backup of your original file.
