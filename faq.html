Frequently asked questions

Are all 70 tools free?

Yes. There are no paid plans or required accounts for the image toolkit.

Which formats can I export?

The converter offers PNG, JPG, WebP, BMP, ICO, GIF, PDF and Base64 options; support varies by browser and source. Animated images may become still frames.

Does the upscaler restore missing detail?

No. It uses browser resampling and sharpening. Background removal is color-based. The SEO assistant generates editable text from supplied information.

Why is a compressed file still large?

File size depends on dimensions, complexity and output format. Read our compression guide.

Are images uploaded?

The current studio processes images and files locally. Authentication and external libraries use separate network requests. Read the privacy policy.

How do I report a problem?

Use the contact page and include the tool name, browser and steps to reproduce without sensitive files.

Can I create ZIP archives or merge PDFs?

Yes. The file and PDF studios use local browser processing with downloadable outputs. The advanced workspace accepts up to 100 files or 100 MB per run, and some tools have stricter limits. Password-protected PDFs and some archive formats are not supported. Review results before using them.
